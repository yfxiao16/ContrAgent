# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1.

In short: be respectful and constructive in issues, pull requests, and
discussions; assume good faith; focus on what is best for the project
and its users. Harassment, personal attacks, and discriminatory language
are not acceptable.

Reports of unacceptable behaviour can be sent to the maintainer listed
in `CITATION.cff`. Reports are handled confidentially.
